# 净化标签

技能以五个规范角色说话。本文件把角色映射到本仓库议题入口实际使用的标签字符串。

| 技能中的角色 | 本入口的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估此议题 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整描述，可交给 AFK 代理执行 |
| `ready-for-human` | `ready-for-human` | 需要人类实现 |
| `wontfix` | `wontfix` | 不做 |

技能提到某个角色（如「打上 AFK-ready 净化标签」）时，使用本表中对应的标签字符串。

本仓库采用默认标签：角色名即标签名，无差异。若未来自定义（如用 `bug:triage` 指代 `needs-triage`），只改此表右列即可。
