# 提醒仅用一次性订阅消息，点餐即授权、截止时一人一条

微信长期订阅消息仅向政务民生、医疗、交通等线下公共服务开放，家庭场景不可用；一次性订阅消息的配额是「授权一次 = 下发一条」，且必须由用户点击行为触发、不得诱导订阅（运营规范 5.21）。据此，提醒通道被设计为：成员提交点餐时请求订阅授权，餐次截止并产出备餐汇总后，向该餐次所有授权过的成员各发一条订阅消息（内容为定案摘要 + 备餐清单入口）；未授权的成员打开小程序即可看到汇总，不做「还没点的人」的主动推送。

该映射使配额账一对一（点一次餐 = 授权一次 = 收一条），既不浪费也不超发；产品上订阅请求只挂在「提交点餐」这一自然动作上，不设任何强制或利诱。

## Consequences

- 提醒颗粒度与点餐行为绑定：某人为多个餐次点餐则多次授权，漏授权则不再补发。
- 「谁还没点」仅能在餐次页内查看，不做主动催点推送。
